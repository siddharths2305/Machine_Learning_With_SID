# Machine Learning With SID 🤖

Hey there! 👋 Welcome to my Machine Learning learning journey repository. This repo contains hands-on implementations of core ML algorithms, along with some exploration into NLP and retrieval-based conversational AI.

## 📂 Repository Contents

| File | Description |
|------|-------------|
| `Linear_Regression.ipynb` | Implementation of simple linear regression |
| `Multiple_Linear_Regression.ipynb` | Linear regression with multiple independent variables |
| `polynomial_regression.ipynb` | Polynomial regression for non-linear relationships |
| `Support_vector_regression.ipynb` | Support Vector Regression (SVR) implementation |
| `Salary_Data.csv` | Sample dataset used for regression models |
| `vectorretriever.ipynb` | Vector-based document retrieval for NLP/RAG workflows |
| `conversationqa.ipynb` | Conversational question-answering implementation |

## 🎯 Purpose

This repository is a personal learning space to:
- Practice and understand fundamental machine learning algorithms
- Build intuition for regression techniques (Linear, Multiple, Polynomial, SVR)
- Explore modern NLP concepts like vector retrieval and conversational QA systems

## 🛠️ Tech Stack

- **Python**
- **Jupyter Notebooks**
- **scikit-learn**
- **pandas / numpy**
- **matplotlib / seaborn** (for visualization)
- NLP/RAG libraries (e.g., LangChain, vector stores) for the retrieval & QA notebooks

## 🚀 Getting Started

1. Clone the repository
   ```bash
   git clone https://github.com/siddharths2305/Machine_Learning_With_SID.git
   ```
2. Navigate into the project folder
   ```bash
   cd Machine_Learning_With_SID
   ```
3. Install the required dependencies (create a virtual environment if you'd like)
   ```bash
   pip install numpy pandas scikit-learn matplotlib jupyter
   ```
4. Launch Jupyter Notebook and explore
   ```bash
   jupyter notebook
   ```

## 📈 Notebooks Overview

- **Regression Series**: Start with `Linear_Regression.ipynb`, then move to `Multiple_Linear_Regression.ipynb`, `polynomial_regression.ipynb`, and finally `Support_vector_regression.ipynb` to see how regression techniques evolve in complexity.
- **NLP Series**: `vectorretriever.ipynb` and `conversationqa.ipynb` dive into retrieval-augmented generation (RAG) style workflows for question answering.
